## 1. Dependencies (download once, ~5 minutes)

Put these into `external/` (the CMakeLists finds them automatically):

| Library | Where to get | Put here |
|---|---|---|
| **GLFW** (64-bit Windows binaries) | https://www.glfw.org/download.html | `external/glfw/` (must contain `include/` and `lib-vc2022/` or `lib-vc2019/`) |
| **GLAD** (API: `gl`, version 3.3, profile: **core**) | https://glad.dav1d.de → Generate → zip | `external/glad/include/` ← the `include/` folder; `external/glad/glad.c` ← `src/glad.c` |
| **GLM** (headers only) | https://github.com/g-truc/glm | `external/glm/glm/` ← the `glm/` folder from the repo |
| **stb** (2 headers) | https://github.com/nothings/stb | `external/stb/stb_image.h` and `external/stb/stb_easy_font.h` |

After this step the tree looks like:

```
SnakeTorus/
├── CMakeLists.txt
├── src/main.cpp
├── shaders/...
├── assets/skybox/...
├── tools/make_skybox.py
└── external/
    ├── glfw/{include, lib-vc2022}
    ├── glad/{include, glad.c}
    ├── glm/glm/...
    └── stb/{stb_image.h, stb_easy_font.h}
```

## 2. Build

**Option A — command line (2 commands, works on a clean machine):**

```
cmake -S . -B build
cmake --build build --config Release
```

Run: `build\Release\SnakeTorus.exe`

**Option B — Visual Studio (what you are used to):**

```
cmake -S . -B build
```

then open `build\SnakeTorus.sln`, set `SnakeTorus` as startup project, F5.

## 3. Controls

| Key | Action |
|---|---|
| Arrow keys / WASD | steer the snake on the torus surface |
| **T** | toggle cel shading (headline technique, on/off) |
| **P** | pause animation |
| **H** | help overlay |
| **R** | restart after game over |
| **C** | toggle camera: orbit / follow-the-head |
| **J / L** | rotate light azimuth |
| **I / K** | rotate light elevation |
| Left mouse drag + wheel | orbit / zoom camera |
| Esc | quit |

## 4. Technique summary (for the report)

- **Torus snake:** the snake lives on a GRID_U x GRID_V grid wrapped on the torus
  surface; position from the parametric equation
  P(u,v) = ((R + r cos v) cos u, r sin v, (R + r cos v) sin u).
  Moving past a grid edge wraps around (torus topology) — no borders.
- **Cel shading:** quantized diffuse term `d = floor(NdotL * 3) / 3` in the
  fragment shader + hard specular step + ink outline via inverted hull
  (scaled copy, front-face culled). Toggle with **T** to compare with smooth Blinn-Phong.
- **Skybox:** cubemap sampled by a cube rendered with `gl_Position = pos.xyww`.
- **Light:** rotating directional light (J/L/I/K) so shading is not baked.
